# Code of Conduct

## 1. Purpose
This Code of Conduct outlines the expected behavior of all members collaborating on this software development project. Its aim is to foster a respectful, productive, and professional working environment.

## 2. Team Values
- **Respect**: Treat all members and their ideas with consideration.
- **Collaboration**: Work together through open and constructive communication.
- **Integrity**: Be honest about work, contributions, and challenges.
- **Quality**: Write clean, maintainable, and well-documented code.
- **Accountability**: Complete assigned tasks on time and support team goals.

## 3. Expected Behavior
### 3.1 Communication
- Communicate respectfully and clearly.
- Respond to team messages within agreed timeframes.
- Seek help early when needed.

### 3.2 Collaboration
- Contribute fairly to project tasks.
- Participate in scheduled meetings or inform the team in advance if unavailable.
- Provide constructive feedback during code reviews.

### 3.3 Professionalism
- Follow established coding guidelines.
- Write meaningful commit messages.
- Document code, issues, and decisions clearly.

## 4. GitHub Responsibilities
### 4.1 Branching and Commit Practices
- Use feature branches for new development work.
- Commit frequently with descriptive messages.
- Avoid pushing directly to the `main` branch.
- Submit pull requests for all code changes.

### 4.2 Issue Tracking
- Use GitHub Issues to track bugs, tasks, and improvements.
- Assign issues to responsible team members.
- Provide clear descriptions and acceptance criteria.

### 4.3 Code Reviews
- Review code respectfully and objectively.
- Request changes only when necessary.
- Approve PRs once they meet quality standards.

## 5. Meeting Conduct
- Start and end meetings on schedule.
- Come prepared with updates.
- Respect speaking turns.
- Document major decisions for reference.

## 6. Conflict Resolution
If disagreements arise:
1. Discuss respectfully within the team.
2. Consider alternate approaches.
3. Document agreed-upon decisions.
4. Involve the instructor only when necessary.

## 7. Academic Integrity
All team members must:
- Produce original work.
- Avoid plagiarism.
- Credit external resources or libraries used.
- Adhere to the institution's academic policies.

## 8. Violations
Failure to comply may result in:
- Reassignment of responsibilities.
- Reduced contribution grading.
- Escalation to the instructor.

## 9. Acknowledgment
By contributing to this project and this repository, all team members agree to follow this Code of Conduct.
